Print Test Sheet (regular printer, letter paper)

Builds a real, scannable preview of your selected labels on standard 8.5"×11" paper — useful for a quick scan-test before printing the full batch on the Zebra.
Important: when the print dialog opens, set scale to 100% / Actual size — not "Fit to page." Scaling changes the QR module width, so a shrunk label can look fine but fail to scan even though a true-size one would work.
This preview uses real QR and barcode encoders, positioned proportionally to your printed labels — it is meant for confirming overall size and running an actual scan test, not for pixel-exact placement matching the ZPL output.
